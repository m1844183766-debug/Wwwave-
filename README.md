# WWWave Studio — Review Website

A static review website containing Work, About and Services, with project films, photography and interactive case galleries.

## Preview

Open `index.html` in a browser. Keep `assets/` and `films/` alongside the HTML files. GitHub Pages serves this repository from the `main` branch root.

The first visit includes the loading ring and autofocus opening. Returning from About or Services to Work or Contact skips that opening. The SHOOT button replays the camera experience.

## Review content

Videos retain their full running time and audio, compressed to web resolution. Images are optimized for viewing. This is a review edition.

Contact details and social QR codes are explicitly marked as demo placeholders. Replace them before using them as actual studio contact information.

The livestream services image is an AI-generated generic studio concept. The team biographies were condensed from the supplied team reference. Brezi, Looki and Speediance logos use the supplied restored assets.

## Local source

The editable working site is maintained separately from this compressed online package. Update the source, regenerate the web package, and publish it to this repository.
